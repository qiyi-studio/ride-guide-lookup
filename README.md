# 📖 遊樂園設施快查

> 遊客問「這個設施幾公分才能玩？」的當下，服務人員在幾秒內找到那個設施的**遊玩規則與範例**，一鍵複製回覆。

單一 HTML 檔，用瀏覽器打開就能用。**不需要安裝、不用連伺服器、手機電腦都能開。**

> 📌 這個公開版內建的是**示範資料**（虛構的遊樂園與設施，不是任何實際園區）。
> 程式邏輯、目錄結構、搜尋與複製功能都是完整的，換成自己的資料即可正式使用。

---

## 為什麼做這個

設施規則原本散在一份多分頁的試算表裡：每個園區一個分頁，快速通關規定又另外一頁，
園區服務（置物櫃、租借）再另外一份文件。

遊客在櫃台前等的時候，服務人員要先想「這個設施是哪個園區的」、翻到那個分頁、
在幾百列裡上下找，找到之後再手動把規則跟範例挑出來重打一次
—— **一次要一兩分鐘，而且很容易把相近的設施講錯**（碰碰車 vs 復古碰碰車、鬼影迷宮 vs 廢棄醫院的年齡限制）。

這個工具把**所有分頁併成一份目錄**，選園區或直接搜名稱，
右邊立刻出現規則與範例，按一顆按鈕就複製成能貼給遊客的格式。

## 功能

| 功能 | 說明 |
|---|---|
| 手冊式目錄 | 左邊 **園區 → 設施類型 → 設施** 三層，像翻一本規則手冊 |
| 即時搜尋 | 上方搜尋框直接打設施名稱，結果依園區分段並標亮命中的字 |
| 繁簡都查得到 | 打繁體找得到簡體原表，打「云霄飞车」找得到「雲霄飛車」 |
| 內文也搜得到 | 不只搜名稱，規則內文裡的字也搜得到（例如「身高限制」「孕婦」） |
| 類型總說明 | 有些類型本身有一段共用規則（例如水上樂園滑水道的泳裝規定），點類型標題就看得到 |
| 快速通關標籤 | 快速通關的規定原本是另一個分頁，這裡併在同一個園區底下，用金色標籤區分 |
| 複製給遊客 | 一鍵複製【園區－類型 設施】＋遊玩規則＋遊玩範例＋注意事項，**沒有任何內部欄位** |
| 匯出備份 | 一鍵匯出成試算表格式（Tab 分隔） |
| 手動新增設施 | 按「➕ 新增」填表單就能加設施；同名再存一次＝改內容，**不用改程式** |
| 一打開不列結果 | 預設是待命畫面，選了園區或開始打字才顯示內容 |

## 怎麼用

1. 點右上角綠色 **Code** → **Download ZIP**，解壓縮
2. 用瀏覽器打開 `index.html`
3. 左邊點園區展開目錄，或直接在上面搜尋框打設施名稱（鍵盤按 `/` 可以跳到搜尋框）
4. 點到設施後，右邊按「📋 複製說明文字」就能貼給遊客

工具裡右上角有「❓ 說明」，寫得比這裡更細。

---

## 資料與隱私

- 整個工具就是**一個 HTML 檔**，開啟後所有運算都在你自己的瀏覽器裡完成。
- **不會把任何資料送到伺服器**，沒有帳號、沒有登入、沒有追蹤。
- 你貼上的資料只寫在這台裝置的瀏覽器 localStorage，換一台裝置要重貼。
- 「複製說明文字」只輸出設施名稱、規則、範例、注意事項，不含任何內部欄位。

## 技術

| 項目 | 內容 |
|---|---|
| 前端 | 單一 HTML 檔、原生 JavaScript，**無框架、無 npm 依賴、無建置流程** |
| 版面 | 左側深色目錄欄 ＋ 右側米色紙面內文的「手冊風」；手機版目錄全寬、點設施後內文整頁滑出 |
| 搜尋 | 繁簡折疊 ＋ 去符號正規化 ＋ 名稱／類型／內文分層加權 |
| 新增設施 | 「➕ 新增」表單手動輸入；同名再存一次＝蓋掉改內容 |
| 匯出 | 整份資料匯出成 Tab 分隔文字，可貼進試算表備份 |
| 資料儲存 | 瀏覽器 localStorage（不落地到任何伺服器） |
| 建置 | 資料 JSON ＋ 三段原始碼 → 組成單一 `index.html` |

### 為什麼搜尋要「名稱／類型／內文」分層加權

遊客常常記不得設施的正式名稱，只記得「那個會全身濕的」「有倒轉的那個」。
如果只搜名稱，這種問法一個都找不到；如果名稱跟內文一視同仁，
搜「碰碰車」會被一堆內文提到碰碰車的設施淹掉。
所以命中名稱給最高分、命中類型次之、命中內文最低——
正式名稱查得準，模糊描述也查得到，而且正確的那一筆永遠排最前面。

## 檔案結構

```
ride-guide-lookup/
├── index.html              ← 成品（要用的就是這一個）
└── 原始碼與驗證/
    ├── t1.html             ← 版面與樣式（手冊風）
    ├── t2.js               ← 資料處理、表格解析、搜尋、繁簡折疊
    ├── t3.js               ← 目錄／內文渲染與互動
    ├── tassemble.js        ← 三段原始碼 ＋ 資料 → index.html
    ├── pairs.txt           ← 繁簡對照表
    └── demo-data.json      ← 示範資料
```

## 重建

需要 Node.js（在 `原始碼與驗證` 資料夾裡執行）：

```bash
node tassemble.js
```

一般使用者**不需要做這一段**，日常資料更新用工具裡的「➕ 新增」就好。
